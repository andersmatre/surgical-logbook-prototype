# Instructions for AI assistants working in this repository

The rules for this repository are in [`CLAUDE.md`](CLAUDE.md), and the project guide is in [`PROJECT.md`](PROJECT.md). Read both before you change anything. They apply to every assistant, whichever tool you run in.

In short: run `npm test` before you finish; keep `PROJECT.md` true in the same change; release app files by bumping the version everywhere `CLAUDE.md` lists.
